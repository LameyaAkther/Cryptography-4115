## 1. Introduction

This repository contains my study notes, Python implementations, practical exercises and verified notebook outputs based on the **Introduction to Number Theory and Cryptography Workshop** organized by the Maths and Physics Club, IIT Bombay.

The original workshop repository aims to introduce concepts from number theory and cryptography and implement them using Python.

## 2. Learning Objectives

- Understand divisibility, remainders and congruence relations.
- Implement Euclid's and Extended Euclid's algorithms.
- Solve LCM and linear Diophantine equation problems.
- Calculate modular inverses and modular powers.
- Apply the Chinese Remainder Theorem.
- Understand prime numbers and primality testing.
- Explain classical and modern cryptographic concepts.
- Demonstrate XOR encryption, one-time pad key reuse, Diffie–Hellman and RSA.
- Implement and test the seven questions in the supplied RSA assignment.
